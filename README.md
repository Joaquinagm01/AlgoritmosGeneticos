# TP - Algoritmo Genetico Canonico

## Estructura
- `main.py`: implementacion completa del AG canónico.
- `requirements.txt`: dependencias de Python.

## Ejecucion
1. Crear entorno virtual (opcional):
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecutar:
   ```bash
   python3 main.py
   ```

El programa imprime una tabla por generacion y luego muestra las graficas.
